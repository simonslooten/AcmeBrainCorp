# Job Description - Senior Software Developer

Job Description for Sr. Software Developer

http://www.payscale.com/research/US/Job=Sr._Software_Engineer_%2f_Developer_%2f_Programmer/Salary

Sr. software engineers/developers/programmers are in charge of a team of computer professionals who develop the different software programs sold by software companies or used by various businesses. As the head of this department, they must be able to solve problems that even the intelligent people whom they work with may not be able to handle. Their job is to lead a team in developing products that make work and everyday life easier for the general public or for business employees.

The sr. software developer is responsible for a group of people who must know how to read computer programming languages, which is a difficult task in itself. He or she is also responsible for learning how to use new software provided to them and then showing the team how it works. Sr. software developers also develop software with their team to sell to consumers or to use privately in the business that employs them. Their job is to know how the products that make work more efficient for people operates, and how to improve upon it and fix it when necessary. Sr. software developers generally work normal business hours in an office setting. Work hours for this position are typical business hours, Monday through Friday from 8 a.m. to 5 p.m. Oftentimes they are required to upgrade current software or develop new software that businesses use privately in their own network. This is for efficiency but is also for security reasons, as some businesses do not want their practices leaked when they may terminate an employee. Changing the software in the office on a regular basis is a defense against that problem. The sr. software developer reports to the information technology director when one is employed or the vice president or general manager.

Requirements for this position are usually a master's degree in computer science, computer programming, or information technology. Some make it to this position with a bachelor's degree. Several years of experience in this field are required, as well as the ability to lead.

The sr. software developer is a growing position in many industries today. It requires a technical yet creative mind, and a sr. software developer must be capable of solving difficult problems. 

Sr. Software Developer Tasks

Define and write software specificatons

Write code to create single-threaded or user interface event driven applications, either stand-alone and those which access servers or services.

Use source debuggers and visual development environments.

Test and document software for client applications.

Write, modify, and debug software for client applications.
