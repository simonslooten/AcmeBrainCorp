To get a Kimi API key:
1. Go to the official platform:  
   
https://platform.moonshot.ai/
2. Click 
Get Started
 (or 
Developer Console
).
3. Sign up / log in (email, Google, etc. all work).
4. Once inside, go to 
API Keys
 (usually in the left menu or under your profile).
5. Create a new key.
The key goes into your Hermes profile’s .env as:
KIMI_API_KEY=sk-...
Model name to use in Hermes:
 kimi-k2.6
(Confirmed on their site — K2.6 is listed as kimi-k2.6.)
After you have the key, run hermes model and pick it, or set it manually with:
hermes config 
set
 model.default kimi-k2.6
