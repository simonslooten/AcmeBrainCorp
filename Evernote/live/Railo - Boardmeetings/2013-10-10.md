Subject: 
Upcoming products - New team members

Hi team,

 
As you may already have read, the invitation for
 
railo.io
 
has went out a few minutes ago. There are several things going on at our place here and I wanted to inform you what we have planned. As Mark already has written, this is NDA!!! So please keep it under the hat until we will inform the broader public.

Railo.io

Railo.io
 will be our central storage for all information we need about clients and users using Railo Server. 
Railo.io
 will store stuff like:

-
          
What servers does one have (if they register)

-
          
What extensions are installed

-
          
Can extensions be installed (this means 
railo.io
 will know about the extensions one purchased)

-
          
What patch is running on a machine

-
          
What SLA does the client have

-
          
What support contract may the client have

-
          
Same with Training etc.

Next to this information, 
railo.io
 will allow you to book several cloud services which we will expand over time. For the moment these are planned:

-
          
Error Logging Service

o
   
In your admin you will be able to check a box saying whether your errors are going to be stored on 
railo.io
 or not.

o
   
Then you can log in into 
railo.io
 and have a look at all the server errors, per context, application time etc.

o
   
Additionally you will be able to store session, application etc. data…

-
          
Backup Service

o
   
This service will allow you to back up your Railo settings to 
railo.io
 and distribute them to other servers, rollback etc.

o
   
This will replace the admin synch extension

-
          
Logging Service

o
   
This service will be allowing users to log all their data to 
railo.io
 and search, check, report etc. everything in there.

o
   
It will be similar to 
loggly.com

-
          
Ping Service

o
   
The ping service will be useful for testing the uptime of your servers and measure the data throughput from different locations

o
   
Eventually basic information about the server will be returned as well

o
   
The Morpheus Application Cloud (see below) might be the upgrade path for this service

In addition 
Railo.io
 will store information about our next big thing we are working on which is 
Railo Unleashed
.

Railo Unleashed

Next to 
railo.io
, we are planning and already working on a commercial version of Railo called Railo unleashed. This version will contain the following products (not set in stone yet):

-
          
Morpheus

o
   
Morpheus is a tool that replaces Fusion Reactor and is solely designed to run for Railo. We have basic stuff already implemented and there will be a beta hopefully for CFCamp.

o
   
It will be diving deep into Railo and give you information tools like Fusion Reactor never will be able to like:

§
  
Number of open locks

§
  
% of cache misses/hits

§
  
Tags/s performance

§
  
Other stuff Railo related

o
   
In the first version these are not all implemented yet, but they are coming…

-
          
CodeMetrix

o
   
CodeMetrix is the tool we are all waiting already for a while and that will come in two flavors:

§
  
CodeMetrix Light which will be a debugging template that will display the slowest expressions (colored in a source code display) of the slowest template within the request. This debugging template should make it easy for people to find their biggest performance issues at a glance and make people wanting to put their hands on the full version of CodeMetrix

§
  
CodeMetrix will offer four different functons:

·
         
Display the execution time of every statement in nanoseconds for all files executed (since enabling CM in the Railo Administrator)

·
         
Show the code coverage of your executed code

·
         
Show what HTML has been generated in which CFML line of code. So with one click in your HTML source you will see which line of code generated it (good for hunting down whitespace)

·
         
Show the current execution path through your code (this allows you to see where a certain code fragment has been called from, after the execution)

o
   
Igal is working on CodeMetrix ATM

-
          
Code Raven

o
   
This tool will allow you to check your code at run time and at compile time for code guidelines you define (details soon), This will be Micha’s project

-
          
Railo Tune (RTune)

o
   
This is a tool I particularly like a lot. It will analyze your code at runtime and check recurring things for redundancies. Like queries, functions, includes, http-calls, object method calls etc. If things show redundant results over time RTune will propose to cache these elements with a frontend in the admin. THIS MEANS:

o
   
You can tune your application WITHOUT touching your code. Just like adding indexes to a database 
J

o
   
Micha is already working on RTune

-
          
Whether we are creating a closed source or commercial version of Railo Server is not decided yet, if we do, it will allow you to do something like:

o
   
Obfuscate compiled code

o
   
Encrypt compiled code

o
   
Increased security etc.

All the tools above will be part of Railo unleashed and one will be able to purchase them separately as well. Next to the tools above, Railo Unleashed will contain one year of free 
railo.io
 access to all the tools there (Error logging etc.) And eventually one will get a support contract included optionally as well. But details on pricing will follow soon. You as members of the team are warmly welcome to participate in any beta phase AND you will get to use these tools for free for your personal use (except all the 
railo.io
 services).

We are planning to release these things one after the other with no rush and reasonable beta phases. The planned release for Railo Unleashed is Q1 2014.
 

We are open to any suggestions and comments about this. And thank you to Micha, Mark and Igal for their work they have done already.
