# Railo Commercial

Proposal to commercialize Railo

1. The languages

I think they should be free and open source. CFML 
&
 CFscript should be as lightweight as possible. ‘The Server’ should be as small as possible and should contain not much more than an ODBC (JDBC?) connector and the Extension Manager. New versions of the languages should be free to download.

We will (more strictly) ask people to submit their name and contact details when they download Railo.

Only Major versions (5.0, 6.0) will be released as open source version.

The Open Source version will be released as a simple Jar, War or EAR (this is a tech decision), no installer will be provided.

2. Extensions and Railo.io

All other ’stuff’ that TRC offers is part of the ‘commercial version’. Based on a monthly subscription fee (minimum contract 12 months), a Railo server is registered as a ‘commercial server’ in Railo.io and now has access to ALL TRC’s extensions AND ALL railo.io services.

My suggestion is to manage this with a registration key that is entered into the Railo server and monitored by Railo.io.

I suggest to price this at around € 200,- per month, excl. VAT.

This would also give servers acces to ALL (minor) versions and patches.

3. Railo Developer Edition

All of the above mentioned stuff, for a smaller fee (€ 25,- per month or so). We should think about how to make sure this will not be used as a server contract? This version includes access to a monitored, closed support forums, where the TRC team, preferred partners also ‘add’ stuff 
&
 answer questions. This has no Service Level (no guaranteed response times).

4. Support

Support contracts (SLA) are only available for Commercial Licenses (?) Support for the free version is only available as ‘per ticket’ (priced at around € 500,- (?) per ticket). 

5. ‘The server’

One of the possible directions for the server to develop into is to be/become a ‘generic’ API platform and to again be/become the ‘Super Glue’ that connects anything to everything.
