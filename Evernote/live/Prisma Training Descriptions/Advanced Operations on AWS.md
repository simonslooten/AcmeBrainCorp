# Advanced Operations on AWS

Advanced Operations on AWS is designed to help you deploy, monitor, measure, and scale, in order to improve the performance, availability, and cost effectiveness of your applications and infrastructure running on AWS. You will automate deployments and update of resources and applications on AWS. Hands-on labs cover all subjects with actual applications, resources, and automated load.

This course will help you get the most out of Amazon Webservices by teaching you how to use the advanced features of the platform.

The course is designed for

- Developers

- System Administrators

- Others responsible for managing operations on the AWS platform

Day 1

- AWS Identity and Access Management

- Bootstrapping Amazon EC2 Instances with AWS CloudFormation and Chef

- Amazon EC2 Instances, Amazon EBS Volumes, and Amazon Machine Images

Day 2

- Continuous Integration and Deployment

- Automation with Amazon Simple WorkFlow

- Amazon RDS Management with CLI and AWS CloudFormation

Day 3

- Amazon Elastic Load Balancing and Auto Scaling

- Monitoring and Alarms with Amazon CloudWatch

- Auto Scaling via the CLI and AWS CloudFormation

Day 4

- Logging with Amazon DynamoDB, Amazon SQS and Amazon S3

- Amazon Elastic MapReduce and Hive for log processing

- Programmatic AWS billing and cost allocation reporting

By the end of this course, you will be able to:

- Create new Amazon CloudWatch metrics and utilize them along with existing AWS service metrics.

- Collect and analyze your application and system log files at a large scale with Amazon S3, Amazon Elastic MapReduce, and Hive.

- Conduct advanced automated bootstrapping of Amazon EC2 instances configured with Chef.

- Declare, deploy and update your infrastructure as code with AWS CloudFormation.

- Respond to operational needs by scaling with Auto Scaling.

- Fail away from an AWS Availability Zone.

- Automate tasks with Amazon Simple Workflow.

- Use AWS Identity Access Management to delegate access to your teams and infrastructure components.

- Programmatically access billing and usage data from your AWS account.

Familiar with

- Existing use of Amazon EC2, Amazon EBS, and Amazon S3

- Familiarity with a Unix shell and CLI tools

- Basic familiarity with Ruby or Python scripting and the Bash shell

Preferred skills

- Basic familiarity with Chef, Amazon Linux, Amazon SQS, and AWS CloudFormation.

- Architecting with AWS course
