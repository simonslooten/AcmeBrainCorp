1. Beste overall goedkope combinatie: Broadcast Tools ADMS 44.22 G2 + NetSwitch III
Hardware
: 
ADMS 44.22 G2
 (AES/analog digitale matrix switcher, ~€800-1.300).
4x AES + 4x analog inputs → meer dan genoeg voor jouw 5 bronnen (je gebruikt AES voor digitale studios/automation).
Low-latency matrix switching, silence detection, mixing/fading.
Volledig digitaal, met AES outputs naar je STL/zender.
Control 
&
 Scheduling
:
NetSwitch III
 (gratis Windows software van Broadcast Tools): grafische interface voor 
time-based event scheduling
 + remote manual switching.
TCP/UDP Ethernet + RS-232 control → bedien vanaf elke PC in het netwerk (of remote via VPN/RDP).
Automatische switches op basis van clock/tijd, plus GPI triggers voor extra automatisering.
3. Dante/AoIP upgrade-pad (nog steeds betaalbaar)
Gebruik Dante Virtual Soundcard + goedkope interfaces + Dante Controller.
Route via software met scripts of een eenvoudige Dante-enabled switcher (bijv. CTP of vergelijkbaar).
Scheduling via broadcast automation software (veel pakketten ondersteunen matrix control + time schedules).
