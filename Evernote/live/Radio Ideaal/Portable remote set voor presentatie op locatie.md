# Portable remote set voor presentatie op locatie

Technisch advies: Mobiele 4-kanaals radioset voor remote verbinding met de studio
Simon, voor de 
remote studio
 (Studio 3 of 4) of live verslaggeving vanuit de Achterhoek (bijv. evenementen, agrarische locaties, dorpen) zoeken we een 
mobiele, robuuste set
 met 
4 microfooningangen
 die via 
5G, WiFi of RJ45 (bedraad internet)
 stabiel naar de hoofdstudio stuurt. Dit past perfect in jullie Dante-matrix en Axite-setup.
Top aanbevelingen (2026)
Hier de beste broadcast-proof opties die voldoen aan jullie eisen:
Comrex ACCESS NX Portable + 4-Channel Mixer
 (sterkste overall aanbeveling)
4 mic/line XLR-ingangen (via optionele mixer-dock).
Verbindingen: 
WiFi, Ethernet (RJ45), 4G/5G via USB-modem of ingebouwde opties
.
CrossLock-technologie voor extreem betrouwbare verbinding (zelfs bij slechte 5G).
Touchscreen, eenvoudig in gebruik voor presentatoren/technici.
Uitstekende integratie met studio-codecs en Dante-omgeving.
Ideaal voor remote broadcasts in de verspreide Achterhoek.
Digigram IQOYA TALK
Portable IP audio codec speciaal voor live remote radio.
Ondersteunt meerdere microfoons (uitbreidbaar naar 4 kanalen).
2x 4G/LTE/5G modules, WiFi, 2x Gigabit Ethernet
.
Zeer intuïtief (2-kliks bediening), lage latency, redundantie over meerdere netwerken.
Perfect voor journalisten of remote studios.
Tieline ViA
Zeer flexibel portable codec met veel IP-opties.
Dual Ethernet, WiFi, USB-modems, interne dual-SIM LTE/5G
.
Uitbreidbaar met mixer voor meerdere mics.
Robuust en betrouwbaar voor mobiel gebruik.
Overige overwegingen
Wireless mics
: Combineer met een UHF/Digital wireless set (bijv. 4-kanaals Shure of Sennheiser) die naar de codec gaat via XLR.
Integratie in jullie studio
: Aan de studio-kant ontvang je via een vaste codec (bijv. Comrex of Dante-ingang) en routeer je direct naar de master-matrix → Axite → zender.
Betrouwbaarheid
: Kies altijd redundantie (5G + WiFi + bedraad) + bonding-software. Test in rurale Achterhoek-gebieden.
Prijsindicatie
: €2.500 – €6.000 afhankelijk van accessoires (mixer, modems, cases).
Mijn advies als technisch adviseur
: Start met de 
Comrex ACCESS NX + 4-kanaals mixer
. Dit is gebruiksvriendelijk, schaalbaar en toekomstbestendig voor jullie groei naar #1 regionaal station.
