# CJIB vragen 2018M04

De tool is gebruiksvriendelijk (graag ook een dashboard laten zien zoals dat voor ons zou kunnen werken)
·
         
Er moet een melding worden gegeven wanneer een fout zich voordoet op de website
        WebAnalytics gaan “interessante” gegevens opleveren als gebruik gemaakt wordt van zogenaamd “Client-Side” metingen mbv een stukje JavaScript. Het registreren van fouten in een website kan alleen door server-side metingen in analyses mee te nemen. Logischer lijkt het om een Monitoring-tool te gebruiken voor het melden van eventuele fouten in een website. Prisma IT kan u daarbij helpen.
·
         
De tool moet inzicht geven in de broken links
        Zie antwoord hierboven
·
         
De tool moet de mogelijkheid geven tot a/b testing
        Piwik kent een uitgebreide A/B-testing module
·
         
De tool moet controleren of er spelfouten of moeilijke woorden aanwezig zijn op de site
        Een webAnalytics tool biedt deze mogelijkheden niet. Prisma IT heeft echter wel ervaring met deze functionaliteiten en kan u daarover adviseren.
·
         
De tool ziet toe op de kwaliteit van de SEO
        Piwik kan helpen bij het optimaliseren van SEO scores (
https://matomo.org/docs/search-engine-keywords-performance/#viewing-search-keywords-reports
)
·
         
De tool moet inzicht geven in de toegankelijkheid van de website en signaleert fouten
        Als met “toegankelijkheid” gedoeld wordt op de mate waarin de Webrichtlijnen nageleefd worden: Piwik verzamelt data over het gebruik van websites en maakt analyses op basis van de verzamelde data. Piwik is niet een tool waarmee de inhoud van websites inzichtelijk kan worden gemaakt. Prisma IT heeft echter ruime ervaring met het naleven van Webrichtlijnen en kan u daarin adviseren.
