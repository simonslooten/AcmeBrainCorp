# NS overleg 20171113 (Wim Liet, Maarten, Erik Boshoeve, Jochem, Klaas Brinkman, Kitty, Simon)

Voorstel maken voor samenvoegen van core applicaties. samengevoegde basis waarbij we accepteren dat er verschillen zijn.
SLA tekst over WAT we gaan leveren aan boord.
SLA op OBIS core deel van OBIS meenemen in Boord deel.
DFA voorstel maken OBIS
Het Intellectueel Eigendom (IE) van de code van de ePublisher Core applicatie (de applicatie die op de treinen geinstalleerd is) berust bij NS. NS staat toe dat Prisma IT deze applicatie, in overleg met NS, aanbiedt aan andere partijen. Per keer zullen afspraken gemaakt worden over een commerciele regeling.
