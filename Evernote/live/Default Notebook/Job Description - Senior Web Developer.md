# Job Description - Senior Web Developer

http://www.payscale.com/research/US/Job=Senior_Web_Developer/Salary#CareerPaths

Job Description for Senior Web Developer

Senior web developers are the leads in developing websites. They think much like advertising specialists in that they want to design their web pages to attract traffic to it and therefore to the company and its products. Senior web developers also have an advanced technical know-how with computers as well as the Internet.

Senior web developers are able to collaborate with the team members that they lead to bring all of their ideas together. They must be flexible in working with other teams but also creative and able to implement attractive ideas. Their duties include coding and programming, application testing, page updating, development, webpage maintenance and many other related web and computer duties. They usually report to a marketing director, and senior web developers and their teams work with interactive design teams and project managers.

The common degree required for becoming a senior web developer is a master's degree in computer programming or computer science. However, some have made their way up the the position with a bachelor's degree in computer programming or computer science and some have made it with a degree in graphic arts/design. Senior web developers are also required to have strong leadership ability and several years of experience in web design. They generally work in office buildings where they usually have their own offices. Their work hours are usually standard work week hours.

Senior Web Developer Tasks

Write code to generate web pages, access databases and business logic servers.

Work with with designers and content producers.

Test and document software for web sites.

Write, modify, and debug software for web sites.
