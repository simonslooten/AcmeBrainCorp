  1. Er is een openstaand issue mbt beveiliging ePublisher.

Het betreft hier een URL die van “buitenaf” benaderd kan worden en waarop continu een PBIS playlist afgespeelt wordt.

  

Het gaat hier om een testserver die (langgeleden) in overleg met NS is opgezet (werd door Rozijn bevestigd), om trein-fabrikanten (Alstom, Tatillee) de mogelijkheid te geven om content te kunnen tonen in nieuwe treinen als eerste test (werkt de apparatuur?)

  

De vraag is nu: moet die URL zonder enige security beschikbaar blijven?

  

Afspraken:

\- URL blijft vooralsnog open

\- NS controleert of IP-whitelisting mogelijk is

\- Prisma controleert of de software op deze server de laatste versie betreft en “meelopt” met releases

\- Prisma controleert of een aangepaste (gestripte) player gemaakt kan worden voor deze server, zoals áls er op de server wordt ingebroken, niet een kopie van de productie software wordt aangetroffen en er geen “leermoment” kan zijn over hoe op een trein ingebroken kan worden.
