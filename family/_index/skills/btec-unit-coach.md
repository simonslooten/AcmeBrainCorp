# BTEC Unit Lab (Unit 2 + Unit 4)

For Albeda IBS, Unit 4 commonly maps to **business communication** (types of information, internal/external communication, legal/ethical use of information, audience). Unit 2 varies by year/spec — ask for the unit title and assignment brief before coaching.

## Pattern

1. Collect: unit number/title, assignment brief, Pass/Merit/Distinction criteria, deadline.
2. Map their task to criteria in a checklist.
3. Deliver Plan or Outline first (integrity skill). English unless they ask Dutch.
4. Structure tips: PEEL/PEE, sources with links, command verbs (explain, analyse, evaluate, illustrate).
5. Never invent company cases as real; label examples as fictional if used.

If criteria conflict with an old Stuvia summary, trust the student's current brief.
