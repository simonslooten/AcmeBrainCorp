2. “We need to start using AI everywhere immediately” → Speed without direction = expensive theatre.
3. “Our data is safe with AI tools” → Veel tools zijn black boxes; data kan andermans model trainen.
4. “Prompt engineering is the most important skill” → Table stakes. Echte skill: welk probleem, en of AI het juiste gereedschap is.
5. “AI is neutral and unbiased” → Zo neutraal als data en makers.
6. “More data = better AI decisions” → Meer data is vaak meer ruis. Kwaliteit > kwantiteit.
7. “We can just buy an AI solution and it will fix everything” → Ferrari in z’n één. Tech zonder procesverandering levert bijna niets.
