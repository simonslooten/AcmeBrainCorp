## The five (impact × effort for the *site*)

### 1. Method footnote for “>96% nieuwe rol binnen 3 maanden” — **do first**
**Why:** Sharpest timed success claim on the 8-peer watchlist (CP “ruim 91% snel” has no window; CA “90%”; most peers none). Without method, the claim is a credibility risk if challenged.  
**Site move:** Publish a short, honest method note (cohort, period, definition “nieuwe rol”) next to the claim — CONCEPT already drafted.  
**Artifact:** `_draft-methodologie-96pct.md` (CONCEPT · NEED FROM SIMON for facts).  
**Do not:** Inflate % or invent methodology.

### 2. Cornerstone “kosten & resultaat” hub — **SEO parity without price list**
**Why:** Care4Careers kenniscentrum + CP/Focus/CA public ladders own “wat kost outplacement” Google; CH is silent → loses top-of-funnel.  
**Site move:** Educational hub + supporting articles that cite **market** ranges peers already publish; explain how to read packages; end on CH resultaat/assessment/AI — **no CH SKU grid, no CH € bands**. Optional OP-vs-2e **differentiatie** only as “wij doen dit niet.”  
**Artifacts:** `_draft-wat-kost-outplacement-hub.md`, `_seo-kosten-resultaat-outlines-2026-10-01.md` (both CONCEPT).  
**Do not:** Mirror Focus ★1 (€815) or peer shop race on the homepage.

### 3. On-page bewijsblok: COTAN + psycholoog + AcmeBrainCorp AI + >96%/3m
**Why:** Peers with CEDEO/Blik/OVAL rarely couple those marks to COTAN + agentic AI. Closes “geen keurmerken” optics *on the site* without applying for certs yet.  
**Site move:** One visible proof strip (home and/or dienst pages) — same stack used in proposals. Keep language factual; no “wij zijn CEDEO-kandidaat” on site.  
**Related:** `_cert-clear-recommendation-2026-10-01.md` (research CEDEO OP/loopbaan offline; **no apply / no site claim** until ready).

### 4. Assessment-led OP positioning (messaging lock)
**Why:** Xynthesis / P4P / NK / C4C own spoor-2 / UWV commodity framing (Against-us). CH win zone = assessment-led maatwerk + timed resultaat — not entry-price race. Leeuwendaal owns Gallup/public-sector mindshare; CH differentiates with COTAN + AI + OP %.  
**Site move:** Tighten dienst copy so assessment and outplacement read as one quality path; never pitch 2e spoor; don’t equate Leeuwendaal’s CEDEO (opleidingen scope) with needing “the same CEDEO” on CH.  
**Related:** battlecards + `_win-vs-peers-2026-10-01.md` §2.5.

### 5. Social-proof layer (reviews) — **if missing, plan it**
**Why:** CareerAdvisor 9.2 / Power4People 8+ / Nieuwe Koers review scores compete while CH leans on %. Buyers compare trust marks in parallel with %.  
**Site move:** Add Klantenvertellen / Trustpilot (or equivalent) *only if* real reviews exist or a collection plan is live — no fake widgets.  
**Park if:** No verified review corpus yet → keep % + method + bewijsblok first.
